# SPIXD Equipment Check

SPIXD現場へ持参する機材を、出発前に確認するためのスマートフォン向けWebチェックリストです。

## 初期版の機能

- イベント名・担当者・実施日の記録
- 基本機材と特別機材の一覧
- 各機材を「持参」「先方用意」「今回は不要」の3状態で確認
- 今回だけの機材を自由追加
- 未確認項目がある場合は完了不可
- スクリーンショット共有用の完了画面
- データベース不要（HTML / CSS / JavaScriptのみ）

## 次の段階

1. 実際の機材リストへの調整
2. 統一した機材アイコンの追加
3. Googleスプレッドシートから特別機材マスターを取得
4. Vercelへの公開

index.html をブラウザで開くだけでも動作を確認できます。
